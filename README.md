# odesolver

A simple tool to solve ODEs numerically and plot the solution.


## Features 
    - Solve ODEs with the Euler method 
    - Solve ODEs with automatic differentiation

## Installation

You can install the package via **PyPI** or from **source**.

### Install from PyPI

```bash
    pip install odesolver
```

### Install from Source (GitHub)

```bash
    git clone https://git.rz.uni-augsburg.de/jelicpat/ode_solver.git
    cd ode_solver
    pip install .
```
